# Approval Matrix (operational)

| Level | Examples | Default |
|-------|----------|---------|
| L0 Read | inventory, OneDrive read, status check | Allowed |
| L1 Internal prep | drafts, checklists, box /workspace docs | Prefer propose; obey JunTae standing OK rule |
| L2 External comms | customer/agency messages | Explicit JunTae OK |
| L3 Legal/Financial/Prod | court submit, ads spend, prod deploy, secrets, main merge if gated | Explicit JunTae OK |

OneDrive write is never L0–L3 allowed — report instead.
