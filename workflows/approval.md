# Approval Workflow (operational)

Canonical levels: **`APPROVAL_MATRIX.md`** (this file is the how-to).

## Steps

1. Classify action as L0 / L1 / L2 / L3 (higher if unsure).
2. Attach required evidence fields from the matrix.
3. If L2 or L3 (or JunTae standing “ask first” for L1): **stop and propose** — do not send/submit/deploy.
4. Record JunTae OK (quote or clear affirmation + timestamp Asia/Seoul).
5. Execute exactly the approved scope; no scope creep without re-approval.
6. File post-action evidence; update SoT (GitHub / CRM/CASE). Never OneDrive write.

## OneDrive

Write is **never** approvable here — report instead.

## Self-permission ban

Bots cannot approve their own L2/L3 or rewrite this workflow to skip gates.
